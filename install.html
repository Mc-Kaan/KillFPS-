How to Install

The easiest way is through the Modrinth App or Prism Launcher.

1. Recommended – Modrinth App / Prism Launcher

  • Install Modrinth App or Prism Launcher
  • Search for KillFPS+ or open the modpack page
  • Click Install and select the version you want (1.21.11 / 1.21.4 / 1.21.1)
  • Launch and play

2. Manual (.mrpack)

  • Download the .mrpack from the Versions page
  • In Prism / MultiMC / CurseForge App → Import / Add Instance → select the .mrpack file
  • Wait for mods to download, then launch

Requirements

  • Minecraft Java Edition
  • Fabric Loader (installed automatically by the pack)
  • At least 4 GB allocated RAM recommended (6–8 GB is better)

Tips

  • Use Sodium settings for best performance
  • Shaders work with Iris – start with a light preset
  • Disable resource packs you don’t need to save FPS
