# KillFPS+

Higher FPS, less lag.

Lightweight **Fabric** performance modpack for Minecraft.

## Supported Versions

| Minecraft | Pack Version |
|-----------|--------------|
| 26.2      | Latest       |
| 1.21.11   | v1.0.2       |
| 1.21.4    | v1.0.1       |
| 1.21.1    | v1.0.0       |

## Download

- **Modrinth:** [modrinth.com/modpack/killfps](https://modrinth.com/modpack/killfps)
- **Website:** [mc-kaan.github.io/KillFPS-](https://mc-kaan.github.io/KillFPS-/)

## What's Inside

Focused performance stack:

- Sodium, Lithium, Iris
- ModernFix / ModernFix-mVUS
- FerriteCore, ImmediatelyFast, Entity Culling
- C2ME, NoisiumForked, Krypton
- Sodium Extra, Reese's Sodium Options
- And other carefully selected optimization & QoL mods

No bloat. Only mods that improve FPS, memory usage, or essential quality of life.

## Install

1. Use **Modrinth App** or **Prism Launcher**
2. Search for `KillFPS+` or import the `.mrpack`
3. Launch and play

Recommended: 6–8 GB allocated RAM.
